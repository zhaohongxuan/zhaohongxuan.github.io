## Project Overview

Hank's Blog (https://zhaohongxuan.github.io) — a personal blog built with [Hexo](https://hexo.io/) 6.3.0 and the `hexo-theme-stellar` theme (currently 1.44.0). Content is written in Chinese. The blog owner is Hank Zhao (赵宏轩), covering programming, running, reading, and writing.

The stellar theme is a npm dependency (not a git submodule). Upgrade via `npm install hexo-theme-stellar@latest`, then verify `npx hexo generate` builds without errors.

## Branch Model (important)

- **`src`** — the active development branch. Contains all Hexo config, source markdown files, and this file. All work happens here.
- **`master`** — the deployed GitHub Pages output. Auto-generated by CI; never edit directly.

## Build & Development

- Node version is pinned in `.nvmrc` (20.8.1).
- Local preview server: `npm run start` (runs `hexo clean` then serves on port 4000).
- Regenerate static site: `npm run build` (`hexo clean` + `hexo generate`).
- Create a new post: `npm run draft` (`hexo new draft "Title"`).
- `npm run deploy` references `scripts/hexo_deploy.sh`, which does not exist in the repo. The real deploy path is CI (below).

## Deployment

Pushing to the `src` branch triggers `.github/workflows/deploy.yml`, which installs deps, runs `hexo clean` + `hexo d`, and deploys the generated site to the `master` branch using `hexo-deployer-git` with an SSH deploy key (`HEXO_DEPLOY_PRI` secret). After merging/pushing to `src`, the live site updates automatically via GitHub Pages.

## Structure & Conventions

- **Posts**: `source/_posts/*.md`, named `YYYY-MM-DD-slug.md`. Each post's frontmatter follows the `post` scaffold: `title`, `date`, `cover`, `categories` (e.g. `[散文随笔]`, `[技术分享]`), `tags`, and optionally `excerpt` (a short intro shown on listing pages). Posts set `cover:` (empty is fine) rather than a cover image; images are typically external URLs or hosted via the user's `picgo` repo.
- **Config split**:
  - `_config.yml` — site-wide Hexo config (title, URL, permalinks, theme, deploy target).
  - `_config.stellar.yml` — theme-specific options (sidebar widgets, article excerpt length, comments via utterances, font/style). Note: the theme reads `site_tree.*.leftbar`/`rightbar` keys — the existing `sidebar:` key in this file has always been a no-op (the theme default `welcome, recent` applies instead).
  - `source/_data/widgets.yml` — custom sidebar widget definitions (e.g. the `welcome` widget).
- **Pages**: static pages live under `source/` subdirs (`about/`, `categories/`, `tags/`, `projects/`, `workouts/`), each an `index.md` with `menu_id` frontmatter that wires it into the theme's nav.
- **Scaffolds**: `scaffolds/{post,draft,page}.md` define frontmatter templates for `hexo new`.
- **Search**: `hexo-algolia` generates `db.json` (gitignored) for Algolia search.
- `assets/` contains only a `placeholder` file; images are not stored in this repo.
